A 4 KB Python chess engine: PVS search with a transposition table, quiescence, PeSTO tapered evaluation, and a fixed 40,000-node budget per move. The readable source is `src.py`; `main.py` is the LZMA-packed entrypoint produced by the make.fun kit's compress command.

## Run it

```sh
python3 -P -s main.py
```
